# 🎯 Number Guessing Game

A fun, interactive, and beginner-friendly **Number Guessing Game** built using Python! 

---

## 🎮 How to Play
1. The computer will randomly select a secret number between **1 and 100**.
2. Your task is to guess that secret number.
3. After every guess, the game will tell you if your guess was **Too high** ⬆️ or **Too low** ⬇️.
4. Try to guess the correct number in the fewest possible attempts! 🏆

---

## 🛠️ Features & Learnings
- **Random Module:** Uses Python's built-in `random.randint()` to generate a unique secret number every time.
- **Loops & Conditions:** Implements a `while True` loop alongside `if-elif-else` statements for flawless game logic.
- **User Input:** Takes dynamic integer inputs and tracks the total number of attempts.

---

## 🚀 How to Run the Project
Make sure you have Python installed on your laptop, then run:
```bash
python main.py
```
